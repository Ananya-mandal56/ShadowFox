# ShadowFox – Data Science Internship

This repository contains all the projects completed during my Data Science Internship at ShadowFox.

## About

During this internship, I worked on three levels of projects that helped me improve my practical knowledge of Python, data analysis, data visualization, and Exploratory Data Analysis (EDA).

## Project Structure

### 📊 Beginner_Task
**Project:** Data Visualization Guide

- Learned the fundamentals of data visualization.
- Created different types of charts using Matplotlib and Seaborn.
- Understood how visualizations help present data effectively.

### 🌍 Intermediate_Task
**Project:** Delhi Air Quality Analysis

- Performed data cleaning and preprocessing.
- Conducted Exploratory Data Analysis (EDA).
- Visualized pollution trends using Python, Pandas, Matplotlib, and Seaborn.
- Summarized key findings and conclusions from the dataset.

### 🎵 Advanced_Task
**Project:** Spotify Trends Analysis

- Explored a real-world Spotify songs dataset.
- Analyzed relationships between song features such as popularity, danceability, energy, tempo, and other audio characteristics.
- Created visualizations to identify meaningful trends and insights.

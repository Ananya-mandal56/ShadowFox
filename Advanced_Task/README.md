# Advanced Task - Spotify Trends Analysis

## Project Overview

This project was completed as part of the ShadowFox Data Science Internship.

The objective of this project is to analyze Spotify song data using Python and Exploratory Data Analysis (EDA) to understand the relationship between different audio features and song popularity.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow

- Data Loading
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Statistical Analysis
- Key Findings
- Conclusion
